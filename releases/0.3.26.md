# Current GLM Coding Plan models

## Fixes

- **The GLM Coding Plan picker lists the models Z.AI actually serves.** The new default is GLM-5.3, alongside GLM-5.3-Flash, 1M-context versions of both, and GLM-5-Turbo. The old IDs (`glm-4.7`, `glm-5.1`) were being quietly routed to newer models on Z.AI's side. Claude Code's fast background model is now GLM-5.3-Flash. Thanks @DreDay4u (#86).

## Known limitations

- Tasks that saved an old GLM model ID keep it. Z.AI routes it to a current model. Pick GLM-5.3 in the model picker to make the choice explicit.
