# Readable agent traces

## Tool activity

- **Tool calls read as sentences.** Instead of raw tool names, each call says what it did: "Ran `rg -n createSearchIndex src`", "Read `search-index.ts`", "Searched `src` for toLowerCase", "Edited `search-index.ts` +4 −3", "Fetched `developer.mozilla.org`", "Updated the plan · 3 steps". MCP tools name their server and tool.
- **Groups summarise themselves.** A group of calls is one line, such as "Ran 1 command and 2 searches, read 1 file and edited 1 file", with an icon for each kind. While it runs it reads "Reading 2 files…". Failed calls are counted separately and marked in red.
- **Expanded rows show the work.** Opening a row shows command output, file contents, matched files or a red and green diff. The raw input and output are still there, one click further in.
- **Everywhere you see tools.** The same traces appear in conversations, the board, the quick launcher, subagents and team workers.

## Fixes

- **Raw output stays open while a subagent streams.** Updating a subagent's tool row no longer closes the raw output you were reading.

## Known limitations

- The new traces have been tested in Chrome but not yet in WebKit, the engine the macOS app uses.
