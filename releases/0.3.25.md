# Windows on ARM and app-wide lead guidance

## New

- **Windows on ARM.** A native `PandaCode-Windows-arm64-setup.exe` for Snapdragon and other ARM64 Windows PCs, with automatic updates. `npx pandacode` installs it.
- **One lead guidance for every team.** Settings → Agent teams has a Lead guidance field that applies to every team. A team's own guidance still replaces it for that team, and resetting a team's guidance returns it to the app-wide one. Thanks @ktappdev (#79).

## Fixes

- **The agent team editor is readable again.** The Filter models field is full height, and model names stay visible beside their effort dropdowns. Thanks @ktappdev (#84).

## Known limitations

- The Windows ARM64 build is new and hasn't been tried on a real ARM64 PC yet.
- After app-wide lead guidance is set, an older PandaCode version can't read the saved team library. Clear the guidance before downgrading.
